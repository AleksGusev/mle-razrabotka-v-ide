# Инструмент автоматического построения отчётов по данным (DataFrameReporter)

Этот проект решает проблему быстрой и единообразной предварительной оценки качества данных в формате `pandas.DataFrame`. Класс автоматизирует рутинный процесс проверки структуры таблиц, поиска дубликатов и подсчёта пропущенных значений.

## Какие задачи решает класс DataFrameReporter
* Выводит общую размерность таблицы (кол-во строк и столбцов).
* Считает точное количество дубликатов и их процентное соотношение.
* Автоматически выводит расширенную сводную статистику (`describe`).
* Находит общее число пропущенных ячеек во всём датасете и рассчитывает их общую долю с возможностью гибкого форматирования чисел.

## Инструкция по развёртыванию

### 1. Настройка виртуального окружения
Склонируйте репозиторий, перейдите в папку проекта и создайте изолированное виртуальное окружение:

```bash
python -m venv venv
```

Активируйте его в зависимости от вашей операционной системы:
* **Инструкция для macOS / Linux:**
  ```bash
  source venv/bin/activate
  ```
* **Инструкция для Windows (PowerShell):**
  ```powershell
  .\venv\Scripts\Activate.ps1
  ```

### 2. Установка необходимых библиотек
После активации окружения установите все зависимости проекта одной командой:

```bash
pip install -r requirements.txt
```

## Запуск демонстрационного сценария

Для проверки работоспособности инструмента и формирования тестового отчёта по файлу `data/payments.csv` запустите главный скрипт:

```bash
python main.py
```
